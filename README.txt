SUNLED website - plain HTML, CSS and JavaScript. No install or server needed.

Run:   open index.html in Chrome, Edge or Firefox.
Admin: open admin.html to add, edit and delete products (saved in this browser only).
Photos: put files in assets/images/ and enter the path in admin, or upload a photo in admin.
WhatsApp number: DEFAULT_SETTINGS in js/storage.js (country code 91 + number).
Local Storage is per-browser, not a shared database. Use "Download backup" in admin to move products.
